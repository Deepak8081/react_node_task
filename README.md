A full-stack web application designed for task organization, workflow automation, and structured CRUD operations built with React on the frontend and Node.js / Express on the backend.

---

## ✨ Features
- RESTful API endpoints for creating, listing, modifying, and archiving tasks.
- Responsive React frontend with real-time state synchronization.
- Clean modular architecture separating routes, controllers, and services.

---

## 🚀 Getting Started
```bash
# Backend setup
cd task_/backend && npm install && npm start

# Frontend setup
cd ../frontend && npm install && npm run dev
```
